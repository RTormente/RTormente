# Olá, eu sou Rodrigo Tormente

Profissional de TI com mais de 15 anos de experiência em ambientes corporativos, com trajetória predominantemente voltada a infraestrutura, suporte técnico e sistemas.

Ao longo dessa trajetória, o desenvolvimento sempre esteve presente como uma área de interesse e também como uma ferramenta para resolver problemas. Já desenvolvi e adaptei soluções para necessidades específicas, automatizei tarefas e construí projetos utilizando tecnologias web e outras ferramentas de programação.

Minha experiência profissional principal está em infraestrutura e sistemas, mas também possuo capacidade para desenvolver soluções e projetos pontuais, especialmente quando o desenvolvimento está relacionado à resolução de uma necessidade prática.

Este GitHub reúne esse lado da minha trajetória, com projetos próprios e soluções desenvolvidas utilizando diferentes tecnologias.
